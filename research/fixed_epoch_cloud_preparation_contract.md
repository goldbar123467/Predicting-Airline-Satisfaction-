# Development-only cloud preparation

`scripts/prepare_fixed_epoch_cloud_v1.py` prepares the one authorized private Kaggle package; it never uploads, launches, trains or scores. It preserves the local `fixed_epoch_v1` registry and sources. The new policy fixes one T4 job, a 7,200-second hard timeout, a 6,300-second fitting budget and a 330-second remote generated-data smoke allowance. Cloud runtime establishes session-relative deadlines before bootstrap.

Input integrity is anchored to local registry SHA256 `3118735d18dc0bd77145bfcefd42344c3fcc896e8007e38026807cfd60c2fef0`, the original split, raw training, auxiliary bank and incumbent-selection hashes. The preparation reads split metadata first, derives the 629,671 development IDs from `fold >= 0`, then scans train and auxiliary parquet using that ID predicate. One Arrow CPU thread and 8,192-row batches limit local memory use. Each batch must match the exact frozen development order; duplicates, missing IDs and unexpected order fail. The train target is checked only on those filtered rows. Written subset IDs are read back independently. No audit/test rows, incumbent OOF or credentials are packaged.

The original raw schema is checked from parquet metadata: seventeen float32 measurements, four large-string categories, int64 IDs and int8 binary labels. The auxiliary subset contains exactly thirteen finite float32 expected-rating columns. Auxiliary parent-manifest integrity and its no-satisfaction/no-synthetic-label claims are required. These are provenance checks, not a new independent audit of the original bank's fitting procedure.

The eleven source files are explicit: cloud runtime, cloud adapter, cloud smoke, frozen common/transform/RealMLP/native-loader code, owned-process supervisor helpers, audited cloud numeric-category compatibility and the reviewed dependency bootstrap. The bootstrap remains byte-identical at SHA256 `5886a5301b1b5d0dddcb10499844d13bc38db9b6e16048b10d9deed132865c68`: PyTabKit 1.7.3, Lightning 2.6.6 and torchmetrics 1.9.0, with the probed Kaggle Torch/CUDA stack protected. The portable adapter must have its current six-test generated CPU receipt before preparation.

The bundle has an exact allowlist and byte-verified ZIP readback. The manifest hashes the unmodified runtime template; only the outer `cloud/fixed_epoch_v1/run.py` replaces its one manifest placeholder, avoiding a circular hash. Both payload and local registration copies bind the same registry. Incomplete preparation remains visible and is never overwritten. Metadata requires a private kernel; the separate uploader must explicitly create a private dataset and verify remote privacy before execution.

Four generated Arrow/archive tests passed: audit-labelled sentinel rows and nonfinite audit auxiliary values are excluded before validation; wrong-order/missing/duplicate IDs fail; invalid development targets and overwrites fail; and the ZIP contains only the requested files with matching bytes. Current source also passed compilation. No real-data preparation, cloud operation or model fit was performed by this agent; the coordinator owns those actions and their receipts.

Cloud and local environments are different. All three cloud arms share the pinned cloud environment and its missing-category policy; no cross-platform equality or quality gain is implied. Outer scores remain deferred until all twelve fits and nine endpoint verifications are complete and outputs return for the fixed local evaluation.
